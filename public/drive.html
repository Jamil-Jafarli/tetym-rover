A gear is the DAC code itself, not a percentage of anything: dac = V / 3.3 × 255, so 124 is 1.60 V and 241 is 3.12 V. The wheel trim and the master level below are not applied to it — what you type here is what the pin gets.

Only one at a time. Tap the lit one again to release it, and pressing W / A / S / D releases it too — a hand on the keyboard always wins. A gear has no keyup behind it, so the page keeps saying it means it at 20 Hz; stop reporting and it coasts to 0 % like everything else.

Saved on the server in presets.json, applied immediately — you can retune mid-drive. Holding W and A together uses the wa row, not W and A mixed. If a turn goes the wrong way, swap that row's two numbers.

The geri boxes are the direction relays, one per wheel. One ticked = the robot pivots on the spot; both ticked = it backs up. Any change to them makes the robot stop for about a second first — crossing phase wires while a wheel turns destroys the controller. If a pivot spins the wrong way, move the tick to the other wheel.
Releasing every key coasts to 0 %. STOP, closing the tab, or switching away also drops ENABLE to 0.
